# Pathwaise

Pathwaise curates a personalized, sequenced learning plan for any topic — drawn from freely
available public resources (videos, podcasts, research papers, articles) — and adapts over time
to how you learn best.

- **Free plan**: up to 15 resources per topic, sequenced from foundational principles through
  core concepts to real-world application.
- **Learning-style aware**: a short onboarding quiz sets an initial style profile (visual,
  auditory, reading/writing, hands-on); giving feedback on resources ("helpful", "too slow",
  "too fast") continuously refines it and reorders what's next.
- **Premium** (not yet implemented): unlimited resources per path, continuous cross-course
  optimization as your methodology is learned, priority curation refresh.

No build step, no backend, no dependencies.

## Running it

Open `index.html` directly in a browser, or serve the folder:

```
python3 -m http.server
```

See `CLAUDE.md` for the file layout and data model.
